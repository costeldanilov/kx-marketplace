# Politique de sécurité

## Signaler une faille

N'ouvrez pas d'issue publique.

Utilisez le signalement privé de GitHub (onglet **Security**, puis **Report a vulnerability**), ou écrivez à cdanilov@kymexia.fr.

Indiquez :

- la version du plugin concerné ;
- les étapes pour reproduire ;
- l'impact que vous voyez.

Nous accusons réception sous 5 jours ouvrés.

## Versions suivies

Seule la dernière version mineure de chaque plugin reçoit des correctifs de sécurité.

## Ce qui est hors du périmètre

- Le comportement de Claude Code ou des modèles d'Anthropic : signalez-le à Anthropic.
- Les plugins commerciaux, qui ont leur propre canal de support.
