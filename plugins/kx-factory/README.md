# kx-factory

Le flux d'étapes gardées, du ticket à la release.

- Étapes : spécifier, planifier, coder, relire, vérifier.
- Modes : `confirm`, `auto`, `agent`, `debug`.
- Les portes déterministes passent avant le jugement du modèle.
- Seul un humain approuve, fusionne, livre et déploie.

Dépend de `kx-core`. État : squelette, version 0.1.0.
